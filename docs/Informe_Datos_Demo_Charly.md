## Diapositiva 2 — ¿Qué es el Eye Tracking?

| Aspecto | Descripción |
| :---- | :---- |
| Definición | Herramienta de neuromarketing que rastrea hacia dónde y en qué orden miran los ojos de una persona al observar un estímulo (página web, empaque, anuncio). |
| Objetivo | Entender qué elementos captan la atención, cuánto tiempo se observa cada parte y qué elementos se ignoran. |
| Aplicación | Optimizar diseños y mensajes, asegurando que lo más importante realmente se vea y se recuerde. |

---

## Diapositiva 3 — Metodología

| Paso | Descripción |
| :---- | :---- |
| 1 | El participante se sienta frente a su computadora sobre una superficie plana, con instrucciones para asegurar el buen desarrollo del experimento. |
| 2 | Se le informa sobre la política de privacidad: se registran datos biométricos, pero no se almacena imagen ni sonido de su cámara. |
| 3 | Instrucciones de iluminación: el rostro debe estar iluminado uniformemente y sin ventanas detrás. |
| 4 | Se solicita mantener la cabeza quieta frente a la pantalla durante toda la prueba. |
| 5 | Se solicita permitir el acceso a la cámara del computador. |
| 6 | El participante centra su rostro dentro de un marco verde frente a la cámara. |
| 7 | Calibración: el participante debe fijar la mirada y hacer clic en los puntos rojos sin mover la cabeza. |
| 8 | Finalmente, el participante observa los estímulos preparados para el ejercicio. |

## Diapositiva 20 — ¿Qué es el ejercicio de IAT monódico?

| Punto clave | Descripción |
| :---- | :---- |
| Qué es | Una prueba para saber qué piensa la mente sobre una marca, sin que la persona se dé cuenta. |
| Ejemplo | Si ves la marca Charly y eliges rápido la palabra "Ecológico", es porque tu mente la asocia con algo positivo. |
| Qué importa | No solo qué palabra se elige, sino qué tan rápido se hace. |
| Utilidad | Descubrir la percepción real de una marca, aunque no se diga en voz alta. |

---

## Diapositiva 21 — ¿Qué es el ejercicio de IAT benchmark?

| Punto clave | Descripción |
| :---- | :---- |
| Qué es | El participante ve una palabra (ej. "Ecológico") y debe elegir rápido qué marca se le viene a la mente: Charly o Puma. |
| Qué mide | La velocidad de respuesta, que revela lo que la mente piensa sin pensarlo mucho. |
| Utilidad | Descubrir qué marca está mejor posicionada en la mente del consumidor. |
